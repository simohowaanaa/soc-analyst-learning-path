# Why Detecting Web Attacks Important

## Le constat de départ

Dans la vie quotidienne, on utilise sans arrêt des applications web sans forcément s'en
rendre compte : Spotify, YouTube, Twitter... Ce ne sont pas étonnant que les attaquants
ciblent en priorité les applications web : toutes les organisations en ont, elles
contiennent souvent des données critiques, et les applications modernes sont très complexes
→ beaucoup de vecteurs d'attaque possibles.

Rappel du chiffre Acunetix : **75% des cyberattaques** au niveau applicatif web.

## Le principe clé : prévenir plutôt que guérir

En analysant l'anatomie d'une attaque, le meilleur scénario est toujours de la bloquer dès
sa première phase (lien avec le Cyber Kill Chain : plus tôt on bloque, moins il y a de
dégâts). D'où l'existence de mesures dédiées à la prévention et détection des menaces
contre les applications web :
- WAF (Web Application Firewall)
- IPS (Intrusion Prevention System)
- Règles SIEM

## Point clé

Le rôle de l'analyste SOC est essentiel — même avec un WAF/IPS en place, c'est l'analyste
qui doit détecter les tentatives d'attaque et prendre les mesures adaptées. Les outils
automatisés ne remplacent pas le jugement humain, ils l'assistent.
