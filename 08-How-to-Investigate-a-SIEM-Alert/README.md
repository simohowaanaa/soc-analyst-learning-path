# 08 - How to Investigate a SIEM Alert?

**Statut :** 🟨 en cours (7 leçons, 20 questions — ~2h, niveau Easy)

## Résumé

Synthèse pratique du workflow complet d'investigation d'une alerte SIEM, du début à la fin :
détection, création de cas/playbook, analyse email, analyse réseau/logs, analyse endpoint,
conclusion. Réutilise et combine les outils vus en sections précédentes (SIEM, EDR, Log
Management, SOAR, Phishing Analysis).

## Prérequis annoncés

- Compréhension de base des concepts de cybersécurité
